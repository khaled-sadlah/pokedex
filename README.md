# Pokedex CLI

An educational TypeScript command-line application using PokeAPI to explore locations, catch Pokemon and inspect a local collection.

## Features

- Interactive command loop and help command.
- Location browsing and exploration.
- Catch, inspect and collection commands.
- API response caching.
- Vitest tests for cache and command input behavior.

## Setup and run

Install Node.js compatible with the repository's `.nvmrc`, then run:

```bash
npm install
npm run build
npm start
```

Use `help` in the CLI to see available commands.

## Tests

```bash
npm test
```

Source files are in `src/`. This is a learning project for TypeScript, API integration and command-line application design.
